# MyNanny

MyNanny combines the existing short-term nanny service with Permanent
Placement on the same V2 customer and administration platform.

Programme records:

- `docs/integrated-v2-delivery-roadmap.md` - canonical sprint sequence for
  Permanent Placement, invoices, agreements, email, chat, UAT and production;
- `docs/render-uat-plan.md` - verified Render inventory, cost and UAT controls;
- `docs/permanent-placement-pricing.md` - configurable amounts, approved
  defaults and price-snapshot rules;
- `docs/permanent-placement-interview-credits.md` - acceptance, restoration
  and replacement-cycle rules;
- `docs/permanent-placement-invoices-email-chat.md` - Concierge milestones,
  invoice/receipt controls, email records and protected interview chat;
- `render.yaml` - current production Blueprint; and
- `render.uat.yaml` - proposed UAT Blueprint, not yet applied.

Production deploys from `devmynanny/mynanny`. Do not prepare releases from the
older `daviddiener85/nanny` working copy.
