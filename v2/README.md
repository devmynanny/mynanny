# My Nanny V2

This folder is the new frontend direction for My Nanny.

## Stack

- Next.js 16.2.6 App Router
- React 19.2.4
- TypeScript
- Tailwind CSS v4
- Prisma 7.8 + PostgreSQL
- Zod
- pdf-lib
- sharp
- lucide-react
- Playwright

## Run

```bash
cd /Users/daviddiener/Desktop/nanny_app/v2
npm install
npm run dev
```

## Routes

- `/` - marketing / product shell
- `/screening` - candidate interview flow
- `/review` - reviewer queue
